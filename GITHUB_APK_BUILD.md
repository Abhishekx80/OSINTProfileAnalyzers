# One-click APK build

1. Create a GitHub repository and upload this project.
2. Open **Actions** → **Build Android APK**.
3. Click **Run workflow**.
4. When the run finishes, open it and download the **OSINTProfileAnalyzer-debug** artifact.
5. Extract the artifact ZIP to get the APK.

The workflow builds the existing passive public-profile/OSINT analyzer. It does not add login bypass, credential theft, or private-account access.
